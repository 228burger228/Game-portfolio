# 🚁 Дмитрий (Burger) — Интерактивное 3D Вертолётное Портфолио

Интерактивное веб-портфолио в виде 3D-игры на **Three.js** с вертолётом, процедурной физикой полета, эффектами ветра и звуком.

---

## 🎮 Возможности и особенности

1. **Режим «Автопилот / Экскурсия» (По умолчанию):**
   * Кликайте по станциям в нижней панели: **Главная База**, **Город Мастеров**, **HgStroy**, **Warpath Wiki**, **Eco-Step**, **docFrost**, **Навыки**, **Контакты**.
   * Вертолёт плавно взлетает, летит по реалистичной 3D-траектории с наклоном корпуса и садится на соответствующий Helipad.
   * После приземления открывается модальная карточка проекта с описанием, метриками, тегами и ссылками.

2. **Режим «Свободный полёт» (Ручное управление):**
   * Нажмите `W`, `A`, `S`, `D` или клавиши стрелок в любой момент, чтобы перехватить управление.
   * `Space` / `E` — набор высоты.
   * `Q` / `Ctrl` — снижение / посадка.
   * `Shift` — ускорение (Турбо).
   * `C` — смена камеры: **Следование** (Cinematic Follow), **Изометрия** (Top-down view), **Кабина** (Nose cockpit view).
   * `M` — вкл/выкл звука.

3. **Мини-игра со сбором звёзд:**
   * На островах и между мостами спрятано **10 золотых звёзд**. Их можно собрать в свободном полёте.

4. **Процедурный звук (Web Audio API):**
   * Звук лопастей вертолёта и звуки наград генерируются браузером на лету без необходимости скачивать тяжёлые аудиофайлы.

5. **Мобильная адаптивность:**
   * Сенсорный виртуальный джойстик и кнопки высоты на смартфонах и планшетах.

## 🚀 Как запустить локально

В папке проекта `heli-portfolio`:

```bash
# Установка зависимостей (Three.js, Vite)
npm install

# Запуск локального сервера разработки
npm run dev

# Сборка готового продакшен-бандла в папку dist/
npm run build

# Предпросмотр собранной версии
npm run preview
```

## 🌐 Как выложить в интернет (Бесплатный деплой)

### Способ 1: GitHub Pages (Рекомендуемый для портфолио)
1. Создайте репозиторий на GitHub, например `heli-portfolio`.
2. Загрузите файлы проекта или воспользуйтесь командой:
   ```bash
   git init
   git add .
   git commit -m "Initial commit"
   git remote add origin https://github.com/228burger228/heli-portfolio.git
   git push -u origin main
   ```
3. В настройках репозитория (*Settings -> Pages*) выберите источник `Deploy from a branch` -> ветка `gh-pages` или папка `/dist`. Игра сразу станет доступна по ссылке:
   `https://228burger228.github.io/heli-portfolio/`

### Способ 2: Vercel (Деплой за 1 минуту)
1. Зайдите на [vercel.com](https://vercel.com)
2. Нажмите **Add New Project** -> выберите репозиторий `heli-portfolio` (или просто перетащите папку `dist` в Vercel Drop).
3. Сайт мгновенно появится в сети на бесплатном SSL-домене (например, `burger-heli.vercel.app`).

### Способ 3: Itch.io
* Просто сожмите содержимое папки `dist/` в `.zip` и загрузите в проект на Itch.io с галочкой «HTML5 game».

## 🛠 Как редактировать данные и проекты

Все тексты, ссылки, скриншоты и координаты вертолётных площадок находятся в одном файле:
`src/data.js`
Любые изменения в этом файле автоматически обновляют 3D-мир и карточки проектов.
